# esg-financial-performance-analysis
Analisi strategica per valutare l'impatto dei punteggi ESG su redditività netta ed efficienza emissiva su un panel di 1.000 aziende globali (2015-2025). Utilizza Excel per il data cleaning e KPI modeling, SQL per l'analisi avanzata e Power BI per la visualizzazione executive a supporto del decision-making.
